
# Student Support AI Assistant

AI-powered Student Support and Internship Management Assistant using NLP and Machine Learning.

## Project Overview

This project is designed to help students with academic support, internship-related information, and personalized internship recommendations.

## Features

- Student support through an AI chatbot
- Internship recommendation
- Natural Language Processing (NLP)
- Machine Learning based recommendations
- Intent classification
- Simple and user-friendly interface

## Technology Stack

- Python
- Machine Learning
- Natural Language Processing
- Pandas
- Scikit-learn
- Streamlit

## Project Files

- `app.py` - Main application
- `train.py` - Model training code
- `intents.json` - Chatbot intents and responses
- `requirements.txt` - Required Python libraries
- `README.md` - Project documentation
